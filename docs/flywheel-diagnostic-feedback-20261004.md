## Next structural gap

revision-request.json, design-review-feedback.json or diagnostic-repair.json.
The current failed constructor contains design-review-feedback.json, so the
one-original/one-child transport cannot run another design-review child. Deleting

completed parent, original review response and validation/isolation evidence,
explicit permitted design changes, lineage and the fresh next-attempt budget.
It must retain original failed outcomes and all ordinary source, control, review
and admission gates. This capability is not implemented by this checkpoint.
