# Completed Action attempts to operational observations

Overall maturity remains an engineering estimate of **71%**. Accepted complete
automatic business loops remain **0**. This connects an existing typed exporter
to ordinary execution; it neither admits knowledge nor proves a new Agent run.

The contained behavior workflow invokes `scripts/export-behavior-loop-observations.cjs`
after bounded execution, even when a normally completed task did not pass. The
transport checks the original contract/calibration/recipe digests, contiguous
attempt identities, unchanged checks and controls, and recorded feedback hashes.
Rust independently reconstructs each feedback before exporting its observation
tables. Both rejected and passing attempts remain separately addressable, with
unchanged raw contract/capture files and an index bound to the original loop bytes.
No reviewer, causal lesson, promotion or authority transaction is invented.

A missing terminal loop capture reports incomplete-loop-capture without creating
an observation export. Original partial files remain in the workflow artifact;
absence is not an assessed task failure. Malformed or changed evidence rejects,
and a partial export on a later reconstruction failure stays diagnostic. Export
does not authenticate participant completion, qualify runtime isolation, persist
remote raw bytes or establish knowledge benefit. Existing independent participant
completion and runtime gates retain their separate scope.

Rust integration regression runs the existing deterministic subprocess controller
through a failed attempt and a passing repair, invokes the actual Node transport
and public Rust exporter, verifies both outcome rows and exact raw captures,
and rejects changed feedback and output reuse. Repeated export has an identical
index; missing terminal capture produces no fake observation. These are transport
and reconstruction tests, not real model feedback learning or cloud acceptance.
