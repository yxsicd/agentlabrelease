# Contained behavior execution and real participant Action

The shared Rust controller remains repository-independent. Reviewed profile data
owns candidate/source identities, exact text controls, task demand and checks;
an explicitly selected worker owns framework/host-seam semantics. The current
upload-retention adapter is not a generic Harmony evaluator.

`maintainer-behavior-loop.yml` runs only trusted main. Select a committed reviewed
profile and candidate corpus, a model/route and 1–3 attempts. Preparation freezes
candidate/source Git revision, selected Blob OIDs and SHA256s, compiler bytes,
resolved local Docker image ID and observed Node runtime, controls and independent
expected values before any worker. Sparse checkout and partial-clone filtering
avoid materializing unrelated source assets. Source acquisition failure preserves
original logs and does not become Agent inability. Preparation binds method bytes
before acquisition and rejects changes during that round.

The selected worker runs in a new network-disabled read-only Docker container,
without capabilities, with no-new-privileges, CPU/memory/PID limits and non-root
operator UID. Only staged request/support bytes, the worker and compiler files
are mounted read-only. No Docker socket, Gateway key, references or operator
capture directory is mounted. The wrapper retains command, raw logs, process
status, digests and exact-container cleanup outputs outside source Git. Unsupported
imports, invalid loader/source and worker infrastructure errors remain unqualified
and stop this current diagnostic adapter; they are not killed negative controls.

The real Pi path reuses the existing isolated participant runtime and operator
Gateway capture. Participant mounts contain only its own source/task/feedback,
fresh state, the locked Pi runtime and a blind-case manifest. Preparation forbids
the Release checkout and operator evidence directory. Existing runtime probes
verify external-network blocking, Docker-socket absence, forbidden-path absence
and the attenuated Gateway route. Credentials enter only the operator adapter
step. Rust consumes completed native/Gateway evidence and retained submitted
source before invoking the separate behavior executor. A passing attempt stops
for review; failed behavior requests a fresh bounded repair. The Action fails
if no attempt passes, always retaining partial captures.

No TableGit authority write, case admission, full Harmony/RDB execution, guidance
benefit, cross-repository transfer or automatic knowledge promotion follows.
Captures stay in the Action artifact; source/profile and method code are the only
Git changes. Image IDs freeze each execution cut; the acquisition tag is not a
claim of an immutable upstream tag or a repository-wide environment lock.
