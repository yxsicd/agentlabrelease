## Operational export without an invented lesson

```sh
agentlab-maintainer-skill-flywheel --export-source-suite-observation \
  --stage ORIGINAL_STAGE --suite COMPLETE_SUITE --output NEW_DIRECTORY
```

Rust reconstructs the entire inventory and accepted-reference recovery from raw
captures before selecting a bounded snapshot. It preserves original request,
design, proposal, verifier/runtime and every input/capture/feedback used by the
consumer. It does not copy participant homes, Gateway exchanges or unrelated
files. The 32 MiB aggregate limit is a rejected-input boundary, not truncation.
Partial sequences lacking a complete result cannot use this completed-suite lane;
retain their originals and failures separately.

The snapshot contains `source-stage/`, `source-suite/` and a digest/byte inventory,
plus ordinary runs, analysis_records, calibration_controls, checks and
evidence_files tables. Every capture, scope and inventory file has an evidence
row. No experiment_lessons or knowledge rows are invented. `candidate.json` is
the existing admission interface name for the exact original scope record;
the run explicitly records sourceScopeId, not a generated calibrated task.

The real retained local suite from Action 37131931224 exported six controls plus
reference recovery without another worker or model execution. This is a local
operational projection, not committed TableGit data, cloud runtime equivalence,
semantic approval or a completed flywheel round.

## Reviewed lesson export

```sh
agentlab-maintainer-skill-flywheel --export-source-suite-lesson \
  --stage ORIGINAL_STAGE --suite COMPLETE_SUITE \
  --lesson-review REVIEW.json --output NEW_DIRECTORY
```

Use `agentlab.source_suite_lesson_review.v1` with reviewed=true, verdict=accept,
automaticPromotion=false and unresolvedFindings=[]. Bind scopeSha256,
requestSha256, designSha256, proposalSha256, suiteResultSha256 and
inputInventorySha256. The inventory digest is its exact original byte digest.
Provide id, scope, reviewerId, phenomenon, cause, change, factId, skillId, body
and skillStage=calibration. Scope SHA binds the serialized original scope stored
as candidate.json, not a new case or the whole author request.

checkReviews, scenarioReviews and controlReviews must cover their complete
original inventories exactly once. Each record has id, accepted=true, rationale
and sourceEvidence entries with path plus an exact nonempty original-source quote.
Every control also declares nonempty exercisedByScenarioIds belonging to the
frozen design. The suite must match every declaration and contain at least two
distinct wrong controls, in addition to the existing accepted references and
recovery gate. Retain the exact review with the original evidence.

These checks bind an explicit independent interpretation; they do not mechanically
prove branch reachability, Oracle truth, reviewer identity or absence of hidden
context. A known unexercised branch or swallowed validation remains unresolved:
do not fabricate accept records simply because the suite matched declarations.
Export may retain a rejected snapshot, but produces no analytical lesson tables
when review validation fails. Existing output directories never restart.

lesson_validations tables and promotionContract. Persist and independently read

export before validating the knowledge delta. Historical analyzer identity is
retained separately from the current consumer identity; neither authenticates
the original producer. Wrong-format wrapping, copied status booleans and stale
raw evidence are not shortcuts through this gate.
