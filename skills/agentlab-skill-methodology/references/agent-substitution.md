# Replace the assessed Agent without changing the question

Keep business task, clean seed, model, budget, environment and teacher-help policy
fixed when changing the Code Agent. Record the unavoidable participant/configuration
paragraph change and both task digests; do not label the complete prompt identical.
A new Agent must have a fresh captured home and native thread. A previous solved
poststate is not an independent start.

Pin the actual platform package version, registry integrity, executable digest and
version observed in the actual participant namespace. A host `--version` or a file
in a shared tool volume does not prove runtime adoption. Preserve the original
read-only tool package and use an owning, task-scoped deployment. Record the
exact service/process changes and rollback. Install/update is environment work,
not student solution help; do not assign it participant credit.

Pi Chat Completions and Codex Responses are different gateway contracts. A
successful Chat call does not qualify Responses. Check the actual resolved route,
URL construction, native protocol reconciliation and first provider response.
A Responses-to-Chat shim appending `/chat/completions` needs the API-version
prefix in its selected base URL. Normalize it using the owning gateway contract;
never guess alternative aliases, change credentials or bypass capture. Check
that the same normalization preserves Messages URL construction.

Keep reasoning enabled and record native requested effort separately from
provider-visible effort. Reject or remove an explicitly ignored configuration
key rather than claiming it took effect. A functioning app-server handshake is
not provider or business-task success.

Preserve each failed original request and immutable output revision. A known
pre-tool provider rejection is an integration failure, not student inability.
Repair a proven task-local configuration gap, then create a separately identified
fresh Fork/request. Never resume/replay an unknown original or silently merge the
new run into its predecessor. Empty assistant content with a stop marker remains
an observed termination until raw provider and adapter evidence establish cause.

The frozen independent oracle remains authoritative for grading. Student-written
tests are deliverables, not self-assigned examination scores. Report actor/model
configuration, tool activity, useful progress, solution help and incomplete
coverage separately; changing an Agent does not erase earlier results.
